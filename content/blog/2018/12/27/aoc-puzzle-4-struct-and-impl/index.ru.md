Каждый раз, [решая задачки Advent of Code](https://github.com/antono/aoc2018), я закапываюсь в какую-нибудь интересную тему. На этот раз — структуры в Rust и реализация методов для них.

Чтобы отслеживать смены охранника ([подробности задачи](https://github.com/antono/aoc2018/blob/master/src/bin/4.rs#L1)), я завёл структуру ShiftTimeline:

```rust
struct ShiftTimeline {
    data: Vec<u32>,
}
```

Идея была в том, чтобы хранить в векторе минуты, в которые охранник спал.

> *Структура* (*struct*) — это пользовательский тип данных, который позволяет дать имя и упаковать вместе несколько связанных значений, образующих осмысленную группу. Если вы знакомы с объектно-ориентированными языками, *структура* похожа на атрибуты данных объекта. В этой главе мы сравним кортежи со структурами, покажем, как пользоваться структурами, и обсудим, как определять методы и ассоциированные функции, задающие поведение, связанное с данными структуры. Структуры и перечисления (о них — в главе 6) — это строительные блоки для создания новых типов в предметной области вашей программы, позволяющие в полной мере использовать проверку типов Rust во время компиляции.

Сначала я собирался добавить ещё полей, но в итоге оставил только одно. Держать структуру ради единственного поля особого смысла нет... Но я решил её оставить, чтобы сгруппировать вокруг неё методы. Читаем [Rust Book про методы](https://doc.rust-lang.org/1.30.0/book/second-edition/ch05-03-method-syntax.html):

> *Методы* похожи на функции: они объявляются с помощью ключевого слова `fn` и имени, у них могут быть параметры и возвращаемое значение, и они содержат код, который выполняется, когда их откуда-то вызывают. Однако, в отличие от функций, методы определяются в контексте структуры, и их первый параметр — всегда `self`, то есть экземпляр структуры, у которого вызывается метод.

Начав пользоваться структурой ShiftTimeline, я заметил, что код инициализации данных дублируется:

```rust
let timeline = ShiftTimeline { data: Vec::new() };
```

Поэтому написал простой инициализатор:

```rust
struct ShiftTimeline {
    data: Vec<u32>,
}

impl ShiftTimeline {
    fn new() -> ShiftTimeline {
        ShiftTimeline { data: Vec::new() }
    }
}
```

Теперь, чтобы получить структуру с уже инициализированным полем, достаточно вызвать ShiftTimeline::new(). И ещё один метод — он принимает ссылку на self с доступом на запись к полям структуры:

```rust
impl ShiftTimeline {

    ...

    fn record_sleep_time(&mut self, asleep_at: NaiveDateTime, awake_at: NaiveDateTime) {
       let start_min = asleep_at_time.minute();
       let end_min = awake_at.minute();
       for idx in start_min..end_min {
           self.data.push(idx);
       }
    }
}

...

shift_timeline.record_sleep_time(...)
```
